# CardsByCyn

## Project Overview

CardsByCyn is a website redesign project for Cynthia, the owner of Cards by Cyn, completed as my Senior Project at Athens State University. The goal of the project is to create a modern, responsive website that reflects the layout and organization of her Etsy storefront while giving her business its own dedicated web presence.

## My Contributions

I personally worked on:

- Building the homepage, including the seasonal banner area and featured card displays
- Creating the product categories and product detail pages
- Adding Etsy purchase links so customers can buy items directly from the site
- Developing the About Me and blog sections
- Working on the responsive layout so the site displays well on phones and tablets
- Testing and debugging page layouts and navigation

## Technologies Used

- JavaScript
- HTML
- CSS
- Git and GitHub

## What I Learned

This project helped me improve my understanding of front-end web development, including HTML structure, CSS styling, responsive design, and JavaScript interactivity. I also gained practical experience with planning a real client project, working on a development team, and using Git and GitHub for version control.

## Current Status

The project is currently in development. Future improvements may include publishing the live website, refining the product pages, and expanding the blog section.
